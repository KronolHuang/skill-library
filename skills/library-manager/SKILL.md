# Skill图书馆管理员

用户维护一个本地知识图书馆（Skill图书馆），根目录默认为 `~/Documents/Skill图书馆`，里面收录：

- 技能（来自 `~/.codex/skills`，通过扫描自动登记，元数据解析自 `SKILL.md`）
- 提示词模板、教程手册（集中存放在 `prompts/` 与 `manuals/` 子目录）

> 路径说明：下面所有 `~/Documents/Skill图书馆` 都是默认路径。如果用户的图书馆放在别处，把命令里的路径替换成实际路径。

## 必须主动询问入库的场景

在以下场景，你完成主体工作后**必须主动询问用户**是否加入图书馆，不能等用户提：

1. 用户要求安装 / 下载一个新的 skill（包括用 skill-installer 安装、手动从 GitHub 下载、放到 `~/.codex/skills`）
2. 用户要求你撰写或生成一份 md 格式的提示词、手册、教程、模板
3. 用户整理好一份新的 md 文档并希望长期复用

询问句式参考：

> 这份「<名称>」要加入 Skill图书馆吗？建议分类：<分类名>（回复「入库」或直接给我想要的分类即可）

用户同意后立即入库，不要重复追问。

## 入库命令

```bash
python3 ~/Documents/Skill图书馆/lib.py add <路径> -t <类型> -c <分类>
```

- 类型：`skill`（技能）/ `prompt`（提示词）/ `manual`（手册）/ `tool`（工具）
- 提示词与手册入库时会复制一份到图书馆目录，原文件保留；技能只登记路径
- 用户未指定分类时，根据内容给出建议分类

## 自动分类与整理「未分类」条目

`lib.py` 内置了一套通用领域关键词规则，`scan` 时会自动把技能归到「金融数据 / 图像设计 / 视频创作 / 开发工具 / 文档办公 / 数据工具 / 音频音乐 / 写作翻译」等分类；分类名是动态的，规则命中哪个就生成哪个，不需要预设。

作为 Codex，你在入库时应额外发挥判断力：

- 用户没指定分类时，先读一遍技能内容，给它一个**准确、简洁的中文分类名**（尽量与现有分类风格一致，如「音频音乐」「营销电商」），用 `-c` 传入；不要只依赖关键词，关键词只作为兜底。
- 用户问「给我未分类的技能分类」或「帮我把分类整理一下」时，先跑 `python3 ~/Documents/Skill图书馆/lib.py list` 找出「未分类」条目，逐个读它的 `SKILL.md` 判断合适分类，再用下面命令更新：

  ```bash
  python3 ~/Documents/Skill图书馆/lib.py add <技能路径> -t skill -c <新分类>
  ```

  `add` 按路径去重，已存在的条目会更新分类，不会重复登记。

- 分类名控制在 2–6 个字、简洁直观，避免过细；例如「写小红书文案」应归「营销电商」，而不是单独建一类。

## 可选：为新技能生成封面图

当入库对象是 `skill` 类型时，在登记完成后**主动询问一次**：

> 要我为这个技能生成一张封面图吗？（回复「生成」即可；跳过回复「不用」）

用户同意后，按下面的流程生成：

### 1. 用生图工具生成封面

调用内置 `image_gen` 工具（按 imagegen 技能的要求使用内置工具模式，不要切到 CLI），生成一张**横向 3:2**、与技能主题匹配的封面图。提示词建议结构：

```text
Use case: stylized-concept
Asset type: skill library cover card
Primary request: <技能核心能力的一句话画面>
Style/medium: <插画 / 3D 渲染 / 平面设计等，按技能气质选>
Composition/framing: 3:2 横向，主体居中或偏左，右侧留白
Lighting/mood: <与主题一致的氛围>
Constraints: 不要出现真实品牌 logo；不要出现大段文字；不要水印
```

### 2. 把生成图移到封面目录

生成图默认保存在 `$CODEX_HOME/generated_images/...`，需要把它复制到图书馆的封面目录：

```text
~/Documents/Skill图书馆/app/static/assets/skills/
```

### 3. 文件命名规则（重要）

- **纯英文/数字的技能名**：封面文件名直接用 `<name>.jpg`，前端会自动按名字匹配，无需改任何代码。
- **中文或含特殊字符的技能名**：用一个稳定的英文别名（如拼音）作为文件名，例如 `my-skill.jpg`；然后打开 `~/Documents/Skill图书馆/app/static/skill-guides-zh.js`，在 `window.SKILL_GUIDES_ZH = { ... }` 里登记一条映射：

  ```js
  "<技能在 SKILL.md 里的 name>": {
    cover: "my-skill.jpg",
    tagline: "一句话说明这个技能能做什么",
    canDo: ["能力一", "能力二", "能力三"],
    when: ["适用场景"],
    workflow: ["步骤一", "步骤二", "步骤三"],
    output: ["产出"]
  },
  ```

### 4. 确认生效

生成并放置后告诉用户「封面已生成」，刷新网页 `http://127.0.0.1:8765` 即可看到。不要重复生成已存在的封面（除非用户明确要求换一张）。

## 其他常用命令

- 扫描新技能入库：`python3 ~/Documents/Skill图书馆/lib.py scan`
- 查看馆藏：`python3 ~/Documents/Skill图书馆/lib.py list`
- 搜索馆藏：`python3 ~/Documents/Skill图书馆/lib.py list -q <关键词>`
- 打开可视化界面：`python3 ~/Documents/Skill图书馆/lib.py open`

## 注意事项

- 只登记，不移动、不删除用户的任何文件
- 入库失败（路径不存在、目录里没有 SKILL.md 等）时，把原因告诉用户，不要静默跳过
- 用户问「我有哪些技能 / 图书馆里有什么」时，先运行 `lib.py list` 再作答，不要凭记忆
- 封面图是可选步骤，用户拒绝就不要生成；生成时遵守 imagegen 的内置工具保存规则
